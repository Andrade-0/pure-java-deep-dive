

Primitive Types: for storing simples values
Reference Types: for storing complex values

Primitive Types:

| Tipo (`Type`) | Tamanho (`Bytes`)        | Intervalo / Valores (`Range`)                                             |
| ------------- | ------------------------ | ------------------------------------------------------------------------- |
| `byte`        | 1 byte                   | -128 a 127                                                                |
| `short`       | 2 bytes                  | -32.768 a 32.767 (≈ ±32K)                                                 |
| `int`         | 4 bytes                  | -2.147.483.648 a 2.147.483.647 (≈ ±2 bilhões)                             |
| `long`        | 8 bytes                  | -9.223.372.036.854.775.808 a 9.223.372.036.854.775.807 (≈ ±9 quintilhões) |
| `float`       | 4 bytes                  | Aproximadamente ±3,4 × 10³⁸ (precisão de ~6–7 dígitos)                    |
| `double`      | 8 bytes                  | Aproximadamente ±1,8 × 10³⁰⁸ (precisão de ~15–16 dígitos)                 |
| `char`        | 2 bytes                  | Um único caractere Unicode (ex.: `'A'`, `'B'`, `'C'`, `'1'`, `'@'`)       |
| `boolean`     | 1 bit (conceitualmente*) | `true` ou `false`                                                         |


Reference Types:

Date, Array, String
